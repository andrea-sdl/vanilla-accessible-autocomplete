Accessible searchable select

A searchable view over one native select. The source select remains the form field and fallback.

Integrate

Add it to a plain HTML form

Load the module, give the select an explicit label, and place it directly inside the component.

<label for="country">Country (required)</label>
<accessible-select>
  <select id="country" name="country" required>
    <option value="" disabled selected>Choose a country</option>
    <option value="fr">France</option>
    <option value="de">Germany</option>
  </select>
</accessible-select>
<script type="module" src="https://cdn.jsdelivr.net/gh/andrea-sdl/vanilla-accessible-autocomplete@v0.1.0/accessible-select.js"></script>

For a newer release, replace v0.1.0 with its Git tag. See the README for options, localization, and styling.

Built with native HTML, CSS, and JavaScript. No dependencies or build step.
